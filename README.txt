MAYUMI KASUGA — MULTI-PAGE ARTIST WEBSITE CONCEPT

Upload all files and folders to a GitHub Pages repository.
Pages: /, /music/, /shows/, /shop/, /about/, /checkout/, /admin/

Shared demo data uses browser localStorage (mayumi_demo_v3). The admin and storefront must be opened on the same origin/browser for changes and orders to appear.
All names of releases, merchandise, performances, and all photographs are placeholders. The checkout is simulated; NO real payments are collected.
The admin preview has NO secure login and is not suitable for a production shop. A real deployment requires a secure server-side backend, database, payment provider and verified artist assets.
External Unsplash photos and Google fonts require internet access.
